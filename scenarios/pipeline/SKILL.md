## 业务口径（来自 research/pipeline-business-fit.md，已核对法源）

- 包装决策真实发生地：IND（需描述容器密封系统）→ **III 期/关键临床批是封窗点**（ICH Q1A(R2)：注册稳定性批次必须用拟上市包装）。黄金窗口 = 临床前晚期到 III 期启动前。
- 「研发期企业更愿意尝试贵包装」**无证据**。真实驱动是**稳定性做不出来**（引湿/氧化/亚硝胺/货架期）。对外话术应是「你们加速试验掉含量/结块/出亚硝胺吗」，不是「你们在研发吗」。
- **G1 硬边界**：CSP 无注射剂/生物药方案 → 抗体/ADC/双抗/mRNA/CGT/疫苗一律出局。中国 BD 出海主流恰是这些 → 交易信号必须过 G1。
- 销售预期：本场景是**养线索 + 抢封窗点**，不按转化率考核（按触达率 + 阶段相符度）。

### 回测记录（2026-11-11，样本：`config/cde_class_cache.json` 181 品种）

| 事实 | 数值 |
|---|---|
| 企业×药品 行 | 386（G1/G3 出局 121 = **31%**） |
| 注册分类 | 4类 129 / 3类 124 / 2.x 20 / 1类 2 / 未知 83 |
| 剂型 | D1=3 34 / =2 173 / =1 38 / 待定 141 |
| 期次可匹配行 | **26 / 265 = 10%** |
| 档位（lite） | A 47 / B 161 / C 51 / D 6 |

**两条必须记住的结论**

1. **样本偏后期**：来自亚硝胺 API 清单，76% 是仿制/补充申请、创新改良类仅 17 行 → **不能用来判断「新药早期信号」的商业价值**，只能验证打分链路。
2. **D2 恒定 = 3 导致评分退化为剂型筛选器**：样本内所有 API 都在 FDA 亚硝胺清单上，`D2` 不区分品种；于是「颗粒/胶囊（D1=3）+ 亚硝胺」直接 12 分进 A 档，**不需要任何期次信息**。要真正区分，必须先接通 D3（期次），并重新校准阈值。
3. 附带暴露：`cde_class_cache.evidence` 是自由文本，656 条里 520 条不是固定 4 段（有 5 段）→ **解析必须按内容白名单匹配，禁止按下标取字段**。
